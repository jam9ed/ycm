# Screenshots

Captured with headless Chrome against the local server, at 1440px wide unless
noted.

Chrome on macOS will not open a window narrower than 500px. Asking for less
still writes an image at the width you asked for, but renders at 500 — so the
right-hand edge is silently sliced off and the page looks broken when it is
not. Capture narrow views at 500 and no lower. Regenerate after a design change — these go stale silently.
